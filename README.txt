Elevor360D TripBuddy V1 — FREE APP

Upload the CONTENTS of this folder to the root of a GitHub Pages repository. Enable Pages in Settings > Pages. Open the HTTPS website in Chrome or Edge and use Install App when offered.

Adverts: edit advert-settings.json (enabled, title, description, image path, url). Upload advert image to the same repository, e.g. adverts/promo.jpg and set image to that path. Changes to adverts need an internet connection to load.

Saved trip data is stored in browser localStorage on this device. Export regular JSON backups. Deleting site data or uninstalling may remove records.

This is a NEW offline travel planner inspired by TripBuddy, not a port of the original 2016 PHP/Foursquare live discovery engine. No live nearby venue/event results are provided.

V1.1: Install App button visible in browser even if the install prompt is not available. When clicked, browser installation guidance is shown. Button hidden in installed standalone mode.
